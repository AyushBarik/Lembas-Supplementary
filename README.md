# Lembas: supplementary material

Supplementary material for the CVPR 2027 submission "Efficient Video Retrieval Augmented Generation via Token Allocation",
built with the official CVPR 2027 author kit.

Build: `pdflatex supp && bibtex supp && pdflatex supp && pdflatex supp` (on Overleaf, the main document is `supp.tex`).
The sensitivity figures are regenerated by `fig/sens_split.py` from the JSON files next to it.
